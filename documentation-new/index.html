This page summarizes proposed updates to Drupal's accessibility documentation. The guides below are organized by recommended review priority and editorial order.

  • Green priority (3): Supporting resources and reference material
  • Orange priority (2): Important implementation guides

Each guide includes links to view the current version, proposed changes, and new content variants.
