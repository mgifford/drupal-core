Sustainability baseline, November 2026 (interim)

Interim baseline. One run on 2026-11-26. First run of a new series. Not comparable with the July 2026 report. The July 2026 report used another script, other pages and other themes, and cannot be reproduced.

It measures this repository's fork of Drupal core (12.0-dev at commit eff737307a), not upstream Drupal, with server tracing enabled. The CO2e figures are modelled from transferred bytes. They are not measured energy.

1. Resource use and modelled emissions

Status: Measured for 24 pages. Median per page: 273.3 kB transferred, 27 requests, 0.039 g CO2e (modelled).

Run status: FAIL. These pages did not pass the crawl's checks. Their resource figures are still listed below; this page covers resource use only.

  • /admin/config/content/formats: FAIL, axe violations not in crawl-installed.json. The page loaded and was scanned.
  • /admin/structure/block: FAIL, axe violations not in crawl-installed.json. The page loaded and was scanned.

Method

  • Each page was opened in a new browser context, so nothing was cached, then scanned with axe-core. Bytes are the response headers and bodies of requests to the site that finished while the page was open and being scanned. Requests to other origins are not included.
  • Emissions: CO2.js, Sustainable Web Design model version 4, applied to the transferred bytes. Grid intensity 472.94 g/kWh (2024 global average bundled with CO2.js) for operational energy, 494 g/kWh for embodied energy, no green hosting. This is a model applied to bytes, not a measurement.
  • Tools: playwright 1.61.1, axe-core 4.14.1, @tgwf/co2 0.19.0. Browser: chromium 149.0.7827.55, 1280 by 720 pixels, light colour scheme.
